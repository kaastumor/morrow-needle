## Rules

1. Do not add an entry because work was completed.
2. Add an entry only when evidence changes confidence in the **project thesis,
   contribution, scope or direction**.
3. Link to existing evidence rather than reproducing it.
4. Preserve negative and parity evidence indefinitely while it remains relevant
   to project identity.
5. Re-test distinctiveness as the project matures; an old VALUE entry does not
   permanently prove current value.
6. At horizon completion and wide-angle reviews, read this ledger before deciding
   `continue / simplify / redirect / stop`.
7. If the project can shrink to a method, corpus, protocol or convention while
   preserving the demonstrated contribution, record that as a serious competing
   identity rather than a failure.
