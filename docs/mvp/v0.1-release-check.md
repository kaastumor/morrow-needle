## Deterministic gate commands

The integration gate requires the repository runtime/CI to execute, not merely inspect, at least:

```text
python -m pytest -q
node --test mvp/app.test.js
python scripts/validate_adversarial_corpus.py
python scripts/repository_sanitation.py
```

The corpus validator is an independent fail-closed check of the canonical index and its referenced repository artifacts. The browser projection test additionally exercises every current canonical case through the MVP projection contract.

## Adversarial reconciliation

## Project Health Check

### Alignment and competing identities

1. Incumbent: adversarial legal-research corpus + evaluation protocol, with a thin explorer projection.
2. Smaller: corpus + protocol only, with repository-native inspection and no maintained explorer.
3. Adjacent: a benchmark/product platform with hosting, scoring, authoring and model replay.

Current evidence supports (1) only as a bounded experiment. The MVP makes the existing corpus easier to inspect but has not yet demonstrated user-value superiority over (2). There is no evidence for (3), and the old broader product remains stopped.

### Canonical freshness / complexity

The explorer remains a derived view over one canonical corpus. No new schema, dependency, service, scheduled workflow or durable generated state was required. Existing evidence owners remain authoritative. The principal current risks remain product creep, ontology creep and process creep rather than missing infrastructure.

### Evidence and limits

Technical structural assumptions are covered by deterministic regressions and the independent corpus validator. Public corpus cases remain exposed/regression-only. Structural accessibility/responsive checks do not establish subjective usability or complete browser/accessibility conformance.

### Direction

**continue** — but only into the already sponsor-authorised, evidence-only discovery gate #104. This is not authorization for another implementation horizon. Discovery may remove candidate features from scope and must not implement them.
