# Competing Identities Value Gate — Issue #86

**Date:** 2026-09-23  
**Direction:** **REDIRECT + SIMPLIFY**  
**Primary surviving identity:** **Needle Method + Needle Core**

## Question

Which version of Morrow // Needle actually deserves to exist?

The gate compared four identities on five unseen legal-information questions:

1. **Full Needle**
2. **Needle Core**
3. **Needle Method**
4. **Strong boring baseline**

The cases were fixed before baseline answers and came from:

- AI Act systemic-risk classification;
- EASA / Airbus airworthiness material;
- Schrems II;
- common-charger application dates;
- a Dutch AI Act corrigendum.

No new canonical schema was allowed merely to improve Needle's score.

## Result in one sentence

**The strongest baseline answered all five questions correctly; Method made the
investigation discipline systematic; Core earned narrow persistent value for
stateful/historical/repeated questions; Full Needle added no material value over
Core in this gate.**

That is enough to change the project identity.

## Strong boring baseline

The baseline achieved:

- 5/5 correct conclusions;
- 5/5 primary traps caught;
- no case where persistent Needle machinery was required for raw correctness.

This repeats the lesson from Issues #49 and #59:

> a capable researcher with the right sources and a strong general model is an
> extremely strong comparator.

Needle cannot justify itself by answering ordinary legal questions correctly.

## Needle Method

Method changed zero conclusions.

Its value was different.

It systematically asked:

- source origin vs legal authority;
- presumption vs final legal state;
- target-specific judicial effect;
- scope + application date;
- current vs historical source state;
- language-expression scope;
- forbidden inference;
- uncertainty/abstention.

The strongest Method case was the Dutch corrigendum.

The weakest was the common-charger control, where the method added almost
nothing beyond careful reading.

### Method conclusion

Method survives as a plausible contribution:

> a reusable discipline for making high-risk legal-information distinctions
> explicit, reviewable and repeatable.

It does **not** yet prove a standalone software product.

## Needle Core

Core produced the most informative mixed result.

### AI Act threshold

No persistent object was justified because no concrete model-specific metric
observation existed.

Creating one would fabricate evidence.

Core's contribution was restraint, not serialization.

### EASA / Airbus

Core can preserve the private Airbus artifact and public EASA source
independently.

It has no honest narrow owner for:

> public legal mandate incorporates/requires private technical content.

That gap is recorded.

No schema was added during the gate.

### Schrems II

Core exposed a real canonical defect.

Judicial Holding v0.1 can represent:

- INVALIDITY;
- INTERPRETATION.

It cannot represent the Court's separate positive validity result:

> examination of Decision 2010/87 disclosed nothing to affect its validity.

A VALIDITY candidate intentionally fails the current schema.

The Method can state the proposition correctly.

This is strong evidence against equating ontology completeness with project
value.

### Common charger

Core Temporal earns modest repeated-query value.

Once the two application dates are encoded, queries for different dates/product
scopes are deterministic and fail consistently.

For one question, manual reading remains cheaper.

### Dutch AI Act corrigendum

This is the strongest Core result.

The language-scoped correction contract persists:

- Dutch expression scope;
- exact pre-correction wording;
- exact post-correction wording;
- correction publication date;
- non-listed-language = NO_ASSERTION.

That turns a manually rediscovered historical trap into durable queryable state.

### Core conclusion

Core has real value where the work is:

- historical;
- repeated;
- stateful;
- cross-time;
- cross-language;
- provenance-sensitive;
- intended for later machine querying.

It is not necessary for most isolated legal questions.

## Full Needle

Full Needle failed to earn additional value in all five cases.

Current higher-level surfaces still largely reflect the earlier product era.

Thread knows its original source kinds:

- baseline/continuity evidence;
- mutation;
- change atom;
- temporal;
- lineage;
- provenance.

Retrieval projects the same family.

The runtime does not currently consume newer canonical objects such as:

- Judicial Holding;
- Authoritative Metric Observation;
- Recognized External Determination;

and language-scoped mutation is not a direct Thread source kind.

This is not treated as a defect requiring immediate integration.

It is evidence that:

> architecture coexisting in one repository is not the same thing as an
> integrated valuable product.

For the common-charger control, Full would actively add ceremony over Core.

### Full conclusion

Full Needle loses its presumption as the project identity.

Historical projections remain valid research artifacts and may be useful again,
but each must earn future relevance.

## Competing identity disposition

### Identity A — Full Needle

**Disposition: REJECT AS DEFAULT IDENTITY / PARK SURFACES INDIVIDUALLY**

Reason:

- no added value over Core in this gate;
- previous public-product parity failures;
- many newer Core contracts are not consumed by old projection machinery;
- integration potential is not contribution.

### Identity B — Needle Core

**Disposition: SURVIVES, BUT SMALL**

Core should mean only the persistent substrate that earns itself through
state/history/repeatability:

- evidence/provenance;
- source/text-state primitives;
- identity/lineage where required;
- temporal state;
- narrow non-textual canonical owners;
- small deterministic resolvers;
- adversarial fixture corpus.

No projection belongs in Core by default.

### Identity C — Needle Method

**Disposition: SURVIVES AS PRIMARY CONTRIBUTION CANDIDATE**

Method appears to be the most generally reusable thing Needle has produced.

Its next value claim is not:

> it can answer questions the baseline cannot.

It is:

> it makes consequential legal-information distinctions systematic enough to
> improve review consistency, reproducibility and failure detection across
> sessions/researchers.

That claim requires a future discriminating experiment, ideally with
less-perfectly-framed questions or multiple independent investigators/agents.

### Identity D — Strong boring baseline

**Disposition: PERMANENT COMPETITOR**

It remains excellent for one-off questions.

Needle must continue to beat or complement this baseline, never replace it with
a weaker straw man.

## New project identity

The project should now be understood as:

> **Morrow // Needle is an evidence-first legal research method plus a minimal
> canonical state substrate for legal-information problems where persistent
> provenance, history, scope or repeated querying materially reduce error or
> reconstruction cost.**

This is intentionally smaller than the old full-engine identity.

## What becomes non-central

The following are no longer part of the essential identity merely because they
exist:

- Thread;
- Legislative X-Ray / Dependency Ripple;
- Source Anomaly;
- Half-Life;
- public cards;
- feed/product projections;
- broader retrieval/presentation integrations.

They remain preserved as experimental/historical research surfaces.

They may be reused if a concrete question earns them.

They should not drive new architecture.

## Artifact-shrink result

Needle can shrink conceptually without deleting evidence.

The minimum valuable artifact currently appears to be:

```
Needle Method
+
canonical ownership rules
+
provenance/history primitives
+
small deterministic resolvers
+
adversarial fixture corpus
```

That is significantly smaller than "general legal-change engine."

## Unresolved finding exposed by the gate

Judicial Holding v0.1 lacks a positive `VALIDITY` holding type.

Do **not** repair automatically because the gate completed.

It is now a concrete foundation risk that may be selected later if a research
question needs judicial validity representation.

The current Method can safely preserve the proposition without schema
laundering.

## Kill / future decision rule

If a later independent evaluation shows that Needle Method + strong baseline
reproduces the historical/repeated-state safety benefits without needing Core,
shrink again toward Method + corpus/protocol.

Core earns continued persistence if repeated future cases demonstrate that it:

- prevents consequential historical/state errors;
- materially reduces reconstruction cost;
- enables reliable queries across sessions;
- or preserves provenance a manual workflow repeatedly loses.

Full projections earn re-entry individually, never as a package.

## Direction

**REDIRECT + SIMPLIFY.**

Do not delete historical evidence.

Do not rebuild the old product.

Do not immediately fix every gap discovered by the gate.

The next horizon, if any, must be justified against this smaller identity.
