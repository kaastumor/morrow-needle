## Question

## Competing identities

### A — incumbent

> known-failure reference corpus + exposed regression fixtures + optional
> Needle failure-analysis discipline.

This remains descriptively possible, but the phrase "optional Needle discipline" now gives
too much project-specific credit to practices that excellent ordinary evaluator/postmortem
work can often absorb.

### B — smaller

> **known-failure reference corpus + exposed regression fixtures + minimal evaluation
> discipline**

Failure-analysis first-refusal remains in the Way of Working:

- strong source-linked postmortem first;
- preserve consequential source-state/authority/boundary/reuse structure where it actually
  matters;
- no forced class;
- omit rather than synthesize;
- packet work only when a simpler owner demonstrably leaves useful structure behind.

Those are retained as good project practice.

They are **not** a standing external value claim.

### C — adjacent evaluator/oracle-maintenance artifact

A real evaluator/oracle-maintenance problem exists.

But current evidence does not establish:

- external demand for Needle as an artifact;
- operational dependence on the 81-case corpus;
- operational dependence on Reference Pack v0.2;
- a reliable pre-result selector for cases with incremental Needle value;
- measurable reconstruction/handoff/regression savings beyond excellent ordinary practice.

This identity therefore outruns the evidence.

## Why the standing proof line stops

After #362, continuing by choosing a new "better complexity proxy" would violate the
project's anti-result-seeking rule.

A better next test would need to be independent of favorable case selection and measure an
operational outcome such as:

- reconstruction/reopening burden;
- missed consequential boundaries;
- handoff burden;
- regression-maintenance burden.

The current execution setup cannot measure those independently without substantial
self-grading.

Likewise, public benchmark/tool existence is not direct adoption evidence.

Therefore:

> **stop the standing external artifact-value proof line.**

This stops that hypothesis programme.

It does not stop the sponsored Needle programme.

## Re-entry conditions

External artifact-value work may reopen only if the boundary materially changes, for
example:

- an actual external consumer repeatedly uses or requests the pack;
- measured reconstruction/handoff burden persists under excellent ordinary practice;
- intended use changes materially;
- an independent setup can measure operational delta without self-grading;
- comparator capability changes enough to invalidate the current boundary.

Do not reopen merely because another promising legal example can be found.
