# Morrow // Needle — Active assumptions

Status: **LIVE REGISTER**

Keep this file small. It contains only material beliefs that can change current
architecture or project direction. Detailed evidence belongs in issues, audits,
fixtures, tests and decision records.

Allowed dispositions: **survives / revise / reject / park / experiment**.

| ID | Assumption | Current disposition | Strongest pressure / discriminating evidence |
|---|---|---|---|
| H-01 | Needle's integrated evidence/legal-state discipline can produce materially better understanding than strong EU change tools plus ordinary LLM explanation. | experiment | Broad novelty is rejected. ## Register rules

- Add an assumption only if being wrong could change architecture, project
  direction, or interpretation of evidence.
- Promotion requires a defined claim, a credible alternative, discriminating
  evidence, and understood limitations.
- A belief that no longer affects decisions is deleted rather than archived
  forever.
- A rejected assumption must update the backlog/decision it previously
  supported; do not keep zombie roadmap items alive.
