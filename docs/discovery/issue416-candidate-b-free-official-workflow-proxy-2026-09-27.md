## Structural comparison

### 1. Discovery advantage is **not** established

The Commission Formal Objections page is a real centralized official index for this frozen workload.

Candidate B therefore does not earn a broad “official sources are too fragmented to navigate” claim from these five cases.

### 2. Reconstruction advantage **is** present

The official baseline still requires the decision text to be converted into a normalized answer:

- current OJ-reference state;
- current presumption consequence;
- whether a restriction is partial or total;
- which event owns the state;
- whether an adopted decision changes state now or only in the future;
- what should not be inferred.

The Candidate-B card performs that conversion once and keeps the official evidence attached.

That is more than visual restyling: it is a maintained state projection over legal events.

### 3. The strongest residual is temporal-state handling

Decision (EU) 2025/1457 is the clearest control.

A careless workflow can see a 2025 withdrawal decision and prematurely treat EN 60335-2-60:2003 as withdrawn.

The official act itself prevents that mistake if Article 2 is read carefully:

> the relevant Annex deletion applies from 18 January 2027.

The Candidate-B view makes the separation explicit:

- current state now;
- next already-fixed state later.

This is a genuine safety/reconstruction property, not decoration.

### 4. Restriction handling also survives

The Machinery and Toy cases require the user to retain a partial restriction rather than collapse the result into “valid” or “withdrawn”.

The card preserves the cited reference while separately limiting the presumption scope.

Again, the official acts contain the answer, so this is not a capability-uniqueness claim.

It is a repeat-use normalization advantage.

### 5. Evidence burden is not eliminated

If the user wants to inspect the binding source, the same EUR-Lex acts still need to be opened.

Candidate B reduces **assembly/reconstruction** burden; it does not make source verification disappear.

This distinction is important.

## Predeclared gate

The internal success conditions were:

1. preserve the official-source answer;
2. reduce distinct reconstruction/source-navigation work for multiple cases;
3. make at least one consequential temporal/restriction distinction materially easier to retain;
4. introduce no new unsafe inference.

Result:

- **1 — pass**;
- **2 — pass, narrowly**: the card removes repeated act-to-status assembly, although the official discovery layer is already good;
- **3 — pass**: especially the future-withdrawal control and partial-restriction controls;
- **4 — pass for the frozen current-date workload**.

Therefore the predeclared disposition is:
