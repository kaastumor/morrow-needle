## Decision

# **REVISE — 50 cases / 21 classes -> 50 cases / 18 classes**

No case was deleted.

Three class pairs were merged after a causal-owner red team:

1. `SOURCE_STATE_BACKPROJECTION` +
   `OFFICIAL_TRACKER_UPDATE_LAG`
   -> `SOURCE_VIEW_TEMPORAL_DIVERGENCE`
2. `AUTHORITATIVE_DATA_INPUT_TRIGGER` +
   `AUTHORITATIVE_FINDING_TO_SPATIAL_EFFECT`
   -> `AUTHORITATIVE_EXTERNAL_INPUT_TRIGGER`
3. `LANGUAGE_AUTHENTICITY_SCOPE_ASYMMETRY` +
   `REPRESENTATION_LOCAL_MARKER_IDENTITY`
   -> `EXPRESSION_LOCAL_REPRESENTATION_ASYMMETRY`

The first merge treats leading/backprojected and lagging derived-source state as
directions of one temporal-view mismatch.

The second treats quantitative data and categorical official findings as two
forms of authoritative non-normative external input under unchanged law.

The third treats language authenticity, corrective scope and local marker
identity as expression-local representation facts that require canonical
cross-expression resolution.

## Explicit non-merges

The audit rejected broader collapses where required evidence/state differs:

- procedural silence vs procedural clock suspension vs sub-day precision;
- cross-order incorporation vs Member-State participation vs object cohort;
- machine compliance artifact vs authoritative external input;
- judicial interpretation timing vs judicial validity;
- private-origin recognition vs official authority handoff.

The last pair was deliberately kept separate because a generic
source-role/effect class would recreate the over-broad effect-ontology pressure
already exposed by #209.
