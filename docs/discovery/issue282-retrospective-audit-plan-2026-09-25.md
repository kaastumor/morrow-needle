## Purpose

Look backward across post-#217 research before expanding the corpus again.

This audit is not a novelty audit. The governing distinction is:

> Existing is not useless. Different is not valuable. Novel is not demanded.
> Competition/incumbent doctrine is evidence, not an automatic rejection or validation.

For a **REJECT**, it is therefore insufficient to show that ordinary doctrine already
names the legal concept. The incumbent must also fully predict the consequential
legal-information/representation error without a useful residual corpus boundary.

For an **ADMIT/REVISE**, doctrinal familiarity is not a defect, but the Needle class
must still preserve a bounded reusable failure state that is not merely a restatement
of the doctrine or a generic instruction to research carefully.

## Per-item questions

For each selected item:

1. Does the cited primary material actually establish the claimed state?
2. Are the positives genuinely independent/orthogonal support, or the same doctrinal
   proposition repeated in another instrument?
3. Does the current class definition exceed the evidence?
4. Does the negative/boundary control really exclude the neighbour?
5. Can mature doctrine or a neighbouring class predict the same consequential
   research error without loss?
6. For REJECTs: was the item rejected because it was already known, or because no
   residual corpus value survived?
7. For ADMITs: would removing the Needle label make the regression case materially
   harder to express/test, or merely less neatly named?

## Decision discipline

Defect labels:

- **FATAL** — invalidates the class/rejection or materially contaminates later decisions.
- **REPAIRABLE** — evidence/class wording needs bounded correction before more discovery.
- **TOLERABLE** — imperfection does not change the recorded decision.

No class or case growth is allowed in this audit. A repair should shrink or correct
before it expands.
