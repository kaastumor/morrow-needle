# Morrow // Needle

**Adversarial legal-research known-failure reference corpus + exposed regression fixtures + minimal evaluation discipline for EU legal change.**

Needle preserves difficult, source-backed legal-information failure cases and the evidence
needed to inspect, challenge and reuse them honestly. It is not a legal-news product, a
general legal ontology, a proprietary reasoning method or an automatic research engine.

## What survives

The evidence-backed project form is deliberately small:

- an **adversarial known-failure reference corpus** of exposed legal-information traps;
- **exposed regression fixtures/cases** only where an evidence owner preserves a runnable
  task plus an expected/evaluator contract;
- a **minimal evaluation discipline** for cases where a genuinely new comparative claim
  warrants preregistration, sealing and a strong comparator;
- **Needle Method** as an optional structured handoff/reporting convention;
- canonical persistence only when a concrete task independently earns it.

The strongest project-level value gates did **not** demonstrate a general correctness or
latent-diagnostic advantage over an equally capable source-grounded baseline. In
particular, the sealed #214 pilot produced **0 diagnostic rescues / 0 C-only
regressions**. That scientific null remains binding for its tested claim.

Negative and parity findings are part of the asset, not failed work.

Current terminology deliberately distinguishes the whole reference corpus from its
executable subset: **reference status is corpus-wide; regression status is
case/fixture-specific**. See
`docs/reviews/issue331-external-regression-role-result-2026-09-26.md`.

## Reference role and safe use

The corpus's primary supported role is as a **known-failure reference asset with
case-specific exposed regression fixtures**.

It can support legal failure analysis, evaluation design, debugging and regression-fixture
derivation, but those uses should not be mistaken for a separately demonstrated external
Needle workflow advantage. The useful discipline is retained as project practice; excellent
ordinary source-linked evaluator/postmortem work remains a fully legitimate substitute.

### Use-allocation rule

Start with the **strongest ordinary source-linked postmortem**.

A sufficient postmortem is a valid endpoint. Apply the fuller Needle packet only when
consequential reusable structure remains to formalize, for example:

- a multi-authority or legal-state relationship that must be reconstructed;
- a material historical/source-identity distinction;
- a consequential boundary or opposite-error control;
- scientific/exposure status that changes what future reuse can claim;
- a non-trivial regression conversion or PASS/FAIL contract.

Do **not** add Needle ceremony when the truth is explicit in one stable source, the expected
answer is already supplied, the future regression oracle is nearly tautological, or the
extra packet would add only labels/governance metadata.

This boundary is supported by the bounded #339, #349 and #353 uses and challenged by
#362's predeclared pair, which #375 later downweighted to **directional allocation evidence**
rather than a high-grade independently adjudicated falsifier. It is a practical
**first-refusal discipline**, not a population claim, model-performance claim, or validated
selector for when Needle will add incremental value.

The standing effort to prove a distinct external Needle packet/artifact job is retired.
Reopen that question only from a materially changed boundary such as repeated real external
use, measured handoff/reconstruction burden that ordinary practice fails to solve, or an
independent evaluation setup capable of measuring operational delta without self-grading.

`NO_EXISTING_CLASS_MATCH` remains valid, and omission is preferred over synthetic packet
fields.

Needle is still **not demonstrated as a generic companion for ordinary legal research**.
The first mechanically selected real post-answer use test (#327) returned
`BASELINE_SUFFICIENT`.

## Reuse and citation status

This repository is public, but it currently has **no project license** and no root
`CITATION.cff`. Public visibility should not be interpreted as a general project grant
to reproduce, redistribute or modify Needle material beyond rights that otherwise apply.

The Reference Pack is therefore currently best treated as **publicly inspectable
reference material**, not as an openly licensed dataset/software distribution. Linked or
third-party legal-source material remains subject to its own rights and is not relicensed
by Needle.

Selecting a project license and preferred citation authorship is an explicit owner
decision. See
`docs/audits/reference-pack-external-reuse-contract-2026-09-25.md`.

## Operating posture

Sponsor direction rejects `IDLE BY DESIGN` for the research programme, but this does
**not** mean that every completed task must generate another experiment.

Purposeful operation may be:

- **DISCOVER** — answer a bounded unresolved research question;
- **CONSOLIDATE** — reconcile, compress or retire accumulated project state;
- **USE** — apply accepted corpus/method assets to a real task within their supported
  scope;
- **REVIEW / RELEASE** — prepare or assess a coherent finished surface;
- **MAINTAIN** — preserve correctness, source validity, integrity or cost discipline.

The current mode and sole WIP are always owned by `BACKLOG.md`.

## Historical machinery

Thread, X-Ray / dependency ripple, Retrieval, Source Anomaly, Half-Life, the operational
feed, the Explorer and the repository's older schemas/contracts remain preserved evidence
and research artifacts.

Their existence does **not** make them part of Needle's current identity or create an
automatic maintenance obligation. They become active only when the current horizon
explicitly reactivates them because they own a required safety property, evidence chain or
earned use.

Historical files should normally be preserved rather than rewritten to look current.

## Research discipline

1. Start from a consequential, falsifiable question.
2. Prefer the strongest appropriate primary/official evidence and the strongest boring
   incumbent.
3. Keep source state, authority, legal effect, time, scope, interpretation and uncertainty
   distinct where the evidence requires it.
4. Preserve abstention, negative findings and parity.
5. Do not treat novelty, class count, issue count, citations, commits or research volume
   as value.
6. Add durable complexity only when the simpler owner fails a required distinction, or a
   bounded product/workflow surface independently demonstrates meaningful relative value
   without lowering the evidence-integrity floor.
7. Exposed corpus cases remain regression/reference material; they do not become fresh
   blind validation again.
