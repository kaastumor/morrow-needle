# #477 — Foundational UX review adoption note

Date: 2026-09-27  
Disposition: **ADOPT CORE CORRECTION / BUILD BOUNDED EXPERIMENT**

An independent sponsor-provided review concluded:

> both current regime prototypes explain legal organisation before explaining the regulated world.

Accepted corrections:
- public entry needs a substantive information contract;
- purpose, actor relevance, material scope and practical effect precede relationship exploration;
- a regime overview and an individual-act page are different page types;
- official sources are a strong baseline, not a strawman;
- important qualifications cannot be buried behind generic disclosure;
- maintenance/research tooling is a secondary job.

Not adopted as proven:
- that the proposed order is optimal;
- that users prefer it;
- that a summary-first page creates distinct value over official summaries.

The next experiment is therefore narrow:
> build one summary-first medical-devices landing page from the existing fixture, freeze comprehension tasks first, and compare later against /regime-v2/ plus the strongest official-source workflow.

No second regime or applicability classifier is authorised.
