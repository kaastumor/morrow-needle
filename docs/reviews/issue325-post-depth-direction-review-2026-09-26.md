# Issue #325 — post-depth project direction review

Date: 2026-09-26  
Selected mode: **USE**  
Next WIP: **#327 — real-task post-answer Reference Pack value test**

## Question

Given the frozen 81-case / 26-class reference state, Reference Pack v0.1, the
post-release audit sequence and the completed three-run depth lane, which purposeful mode
has the highest expected information/value gain now?

The comparison is deliberately project-level. It does not ask which unresolved internal
question would be easiest to execute next.

## Current demonstrated asset

Needle currently has:

- a frozen adversarial legal-research regression/reference corpus;
- 81 exposed `REGRESSION_ONLY` cases across 26 classes;
- a minimal comparative-evaluation discipline;
- a deterministic Reference Pack v0.1;
- explicit negative/parity evidence, including #214's hard null;
- post-release audits that substantially clarify provenance, misuse, execution semantics,
  source-system claims, negative-evidence discoverability, class boundaries and support
  independence;
- a completed three-run post-#282 depth lane.

The project does **not** have evidence that Reference Pack v0.1 produces a general
correctness or latent-diagnostic advantage.

It also does not yet have real-use evidence for the released pack. The #301 cold-start
check was explicitly synthetic rather than human/use evidence.

## Recent effort shape

The post-release sequence was useful but increasingly inward-facing:

- #306 — issue-owner mutability / archival integrity;
- #307 — external reuse rights/citation boundary;
- #309 — frozen-corpus concentration/misuse profile;
- #311 — regression/reference execution semantics;
- #313 — post-hoc metamorphic regression derivation;
- #315 — source-system diversity claim repair;
- #317 — negative/null evidence discoverability;
- #319 — class-boundary evidence;
- #321 — class-support independence;
- #323 — final residual-value depth test.

This work improved honesty and interpretation. It also means the next internal audit now
faces a higher burden: it must beat the information gain available from exposing the
accepted asset to a real job.

## Competing identities

### 1. Incumbent

> adversarial legal-research regression/reference corpus + minimal evaluation discipline,
> with Reference Pack v0.1 as the compact external navigation/use surface.

This identity is fully consistent with current evidence.

### 2. Smaller

> frozen corpus index + repository evidence owners, without treating the Reference Pack as
> independently valuable.

This remains plausible because the pack has engineering/reproducibility value but little
real-use evidence so far.

### 3. Adjacent

> a post-answer regression/reference aid used to improve provenance, historical
> reconstruction, repeatability or later inspection of ordinary source-grounded legal
> research.

This does **not** claim diagnostic superiority. It is a narrower use identity that the
Reference Pack's own safe-use contract already permits.

A real task can discriminate identities 1/2/3 better than another taxonomy audit.

## Mode comparison

### DISCOVER

**Potential value**

There are always further questions about coverage, source systems, evaluation coverage,
taxonomy or legal-information mechanisms.

**Why not now**

The corpus is already unusually well-audited internally:

- every class has accepted boundary evidence;
- every class retains adequate distinct support for its stated regression/reference scope;
- concentration and experimental-independence limitations are explicitly recorded;
- source-system precision limits are known;
- #323 completed the preselected depth programme.

Another internally selected scientific/reference question is therefore more likely to add
marginal refinement than to test the project's current use surface.

DISCOVER remains available when a real task exposes a concrete missing distinction.

**Allocation:** not selected.

### CONSOLIDATE

**Potential value**

The project has substantial history, many audits and a large historical issue estate.

**Why not now**

Recent work has already done the relevant compression:

- #288 made BACKLOG the sole mutable live-state owner;
- historical machinery is passive;
- #317 rejected a duplicate negative-evidence registry;
- #319/#321 rejected new maintained boundary/independence registries;
- current orientation has a clear owner hierarchy;
- no current conflicting live-state owner was found in this review.

There is accumulated history, but no concrete ownership contradiction currently large
enough to justify another consolidation pass.

**Allocation:** not selected.

### USE

**Potential value**

USE addresses the largest current uncertainty:

> does the released reference surface add anything materially useful when attached to one
> real legal-information job, within its supported regression/reference scope?

This question is external-facing and can falsify Reference Pack value without changing the
scientific corpus.

It also follows the charter's north star directly:

> solve a concrete EU legal-information question with the strongest defensible method
> first; preserve Needle state only if it materially improves provenance, historical
> reconstruction, repeatability, regression value or later inspection.

**Important #214 boundary**

USE must not become a disguised retry of the failed corpus-assisted diagnostic claim.

Therefore the selected design freezes the ordinary source-grounded answer **before**
Reference Pack consultation. The pack is used only afterward for supported
regression/reference, provenance and inspection purposes.

This cannot establish model/workflow superiority.

**Allocation:** selected.

### REVIEW / RELEASE

**Potential value**

A v0.2 could improve navigation or package additional derived material.

**Why not now**

Reference Pack v0.1 is already reproducible and release-ready.

Known future improvements are either:

- small navigation conveniences;
- unsupported until concrete use demonstrates need; or
- blocked on an owner choice, especially the #307 license/citation decision.

Releasing another pack before real use would risk packaging the packaging.

**Allocation:** not selected.

### MAINTAIN

**Potential value**

Maintenance is justified by concrete correctness, integrity, source-validity, security or
cost triggers.

**Why not now**

- automatic CI was already compressed to the two current shared gates;
- #306 documented issue-owner mutability honestly;
- release reproducibility is validated;
- no new integrity/security failure is active;
- historical machinery is passive by default.

There is no current maintenance trigger with greater expected value than real use.

**Allocation:** not selected.

## Diminishing-return finding

The recent internal work has **not** been useless ceremony. It found real limitations,
prevented overclaiming and sharpened the corpus.

But the marginal pattern has changed.

Several recent questions ended in:

- existing owners are sufficient;
- boundaries are adequate;
- independence is adequate for stated scope;
- do not create another registry;
- do not add another canonical field;
- no corpus/taxonomy change follows.

That is evidence that the project has reached a comparatively mature internal-description
state.

The next high-information move should expose that state to a real task rather than continue
measuring it from another internal angle.

## Selected WIP

#327 is a **one-task USE test**.

The design is intentionally resistant to confirmation bias:

1. define a public official EU intake and mechanical selection rule before inspecting
   candidate substance;
2. select one fresh task without consulting Needle case/class contents;
3. solve and freeze the task using ordinary source-grounded research;
4. only then consult Reference Pack v0.1;
5. count value only if the pack causes a concrete non-duplicative improvement to
   provenance, source-state reconstruction, repeatability, regression mapping or later
   inspection;
6. if ordinary notes are already sufficient, record `BASELINE_SUFFICIENT`;
7. do not hunt a second, friendlier task.

## Why this is not a #214 retry

#214 tested whether providing the corpus/index treatment **before research** improved latent
diagnosis/correctness over an equally capable ordinary source-grounded baseline.

#327 does not do that.

The ordinary answer is frozen first. The pack is then used only in its supported exposed
reference/regression role.

Possible #327 value is therefore limited to the concrete use artifact and cannot be
promoted into:

- correctness superiority;
- latent-detection superiority;
- general workflow superiority;
- population performance.
