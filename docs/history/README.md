Status: **DURABLE HISTORICAL MEMORY — NOT A LIVE-STATE OWNER**

clearer but also made earlier goals, methods, models and working code easier to forget.

## Source discipline

This reconstruction combines:

- accepted GitHub issues, comments, commits, decisions, schemas, fixtures and code;
- prior Morrow // Needle project chats, used to recover original intent and rationale that

Recovered chat framing is historical context, not a new project claim.

## The one-paragraph history

Morrow // Needle began as an ambitious EU legal-change intelligence system: **make legal
change observable**. It aimed to tell a reader what changed, compared with what, who or what
the rule concerned, when the change mattered, and exactly which official evidence supported
the answer. Needle would detect change; Thread would follow a rule's ancestry and descendants
through time. From that ambition the project built a surprisingly complete evidence-first
legal-change engine: Cellar/EUR-Lex ingestion, canonical ASTs, immutable source observations,
provision/rule lineage, multidimensional time, deterministic mutation, semantic Change Atoms,
append-only provenance, retrieval, Thread, X-Ray/dependency ripple, Source Anomaly, Half-Life,
operational update detection and public feed-card projections. The system repeatedly passed
technical/adversarial foundation gates. What failed was not primarily the engineering. Strong
comparative value tests showed that careful official-source research plus a capable model often
reached the same legal conclusions, and the broader product surfaces did not repeatedly produce
enough incremental value to justify their complexity. Needle therefore contracted through
Full Needle -> Core/Method -> Method + corpus/protocol -> frozen known-failure reference corpus
+ exposed regression fixtures + minimal evaluation discipline. Later work built Reference Pack
v0.1/v0.2, explored conditional failure-analysis value, external evaluation/oracle maintenance,
EU operative-state research and finally a minimal Candidate-A Maintenance Delta core. The
earlier machinery remains valuable historical/technical capital; it is **parked unless a real
job earns re-entry**, not erased.

## Durable interpretation rule

Do not confuse these states:

- **REJECTED** — evidence argues against the claim/direction.
- **PARKED** — technically real or plausible, but not currently worth investing in.
- **OPTIONAL / CASE-EARNED** — useful only when a concrete task demonstrates need.
- **HISTORICAL BUT VALID** — earlier subsystem remains internally useful/correct but no longer
  defines current project identity.
- **CURRENT** — part of today's supported identity or active value hypothesis.

A large fraction of old Needle is in the second through fourth categories, not the first.

## Why this history matters now

The current small identity is a scientific achievement, not proof that the earlier work was
wasted. Several current opportunities — evaluation maintenance, failure-to-regression conversion,
EU operative-state reconstruction — are easier to understand when the old machinery is remembered.
For example, Candidate A's governing-time/evidence-owner discipline descends directly from the
old temporal/provenance architecture; Candidate B is closely related to the early legal-state
ownership model; Candidate C inherits the Gold Corpus/adversarial-regression discipline.

The rule is therefore:

> **Contract scope aggressively, but preserve capability memory precisely.**
