What this prototype is testing

Official sources remain authoritative. This page only tests whether a lean manufacturer can understand the operative OJ-reference state without reconstructing the same event chain each time.

It receives no credit for generic monitoring, alerts, or standards-version tracking. Those capabilities already exist in mature products.
