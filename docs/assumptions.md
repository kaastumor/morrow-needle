## Register rules

- Add an assumption only if being wrong could change architecture, project
  direction, or interpretation of evidence.
- Promotion requires a defined claim, a credible alternative, discriminating
  evidence, and understood limitations.
- A belief that no longer affects decisions is deleted rather than archived
  forever.
- A rejected assumption must update the backlog/decision it previously
  supported; do not keep zombie roadmap items alive.
