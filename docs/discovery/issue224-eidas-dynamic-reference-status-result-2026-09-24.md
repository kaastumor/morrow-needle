# #224 result — eIDAS dynamic reference status

Decision: **ADOPT_FOR_DERIVATION**

`DYNAMIC_REFERENCE_STATUS` generalises beyond harmonised standards.

Under eIDAS, qualified trust-service legal effect follows authoritative
trusted-list status. The same ANF validation-service identity is recorded as
historically Granted and currently Withdrawn.

Boundary: trusted lists may also contain non-qualified services, so mere list
presence is insufficient; the authoritative status is the causal fact.

Canonical consequence: add one public eIDAS DERIVATION case. No rename/new
class and no PKI/trust-list infrastructure.
