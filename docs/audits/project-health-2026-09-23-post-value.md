# Project Health Check — post-#49 comparative value gate

Date: 2026-09-23  
Direction: **REDIRECT**

## Gate result

Issue #49 tested the strongest current public-product claim against four real
cases and the strong simpler baseline from the project charter.

Results:

- one initial LOSS that exposed a real integration omission and was repaired;
- two user-understanding PARITY cases where Needle mainly adds machine-safety
  discipline;
- one PLAUSIBLE ADVANTAGE for proactive indirect-dependency discovery;
- zero repeated clear product wins.

This does not satisfy the project's own success condition.

## North-star effect

The “better general EU legal-change feed” interpretation of the north star is
rejected for the current horizon.

The evidence supports a narrower use of the same foundation:

- legal-change audit;
- evidence/provenance inspection;
- temporal-state adversaries;
- silent dependency discovery;
- complex rule-history reconstruction through Thread.

The operational monitor remains useful as an evidence generator and regression
surface, not as a presumed public-product destination.

## Complexity

The comparative gate justified only two bounded read/integration improvements:

1. human-readable Evidence presentation over existing provenance;
2. consumption of explicit Cellar entry-into-force metadata using the already
   frozen P0-E Temporal Assertion model.

No database, queue, UI framework, ranking model, affected-entity ontology or new
analytic primitive was required.

That is a positive architecture result even though the product thesis weakened.

## Largest remaining uncertainty

Thread is the only untested core product question retained by the prior Project
Health decision:

> How did this rule become what it is today?

emendrix already provides rich provision/version histories, so Thread must be
tested adversarially rather than assumed valuable because it is more
evidence-typed.

## Direction

**REDIRECT** to one final comparative gate around Thread / legal-change audit.

No new architecture is authorized by this decision.

If the Thread comparison does not show recurring material improvement over the
strong baseline, stop public-product expansion and retain Needle as a
research/audit engine and regression corpus.
