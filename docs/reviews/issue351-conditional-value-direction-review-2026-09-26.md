# Issue #351 — direction review after orthogonal v0.2 packet-value null

Date: 2026-09-26  
Selected mode: **USE — COMPLEXITY-STRATIFIED FAILURE ANALYSIS**  
Next WIP: **#353 — complexity-stratified packet-value test on case-treatment failures**

## Trigger

The accepted evidence now contains a useful contrast.

### #339 — positive packet value

A mechanically selected open-ended legal failure required:

- non-trivial doctrinal reconstruction;
- historical source-state preservation;
- a two-sided legal boundary;
- careful derivation/exposure handling;
- non-trivial regression conversion.

Needle materially improved the failure-analysis packet beyond a strong ordinary postmortem.

### #349 — packet-value null, v0.2 navigation success

A mechanically selected binary appellate-disposition error required:

- one reported opinion;
- one obvious ground-truth label;
- a nearly tautological regression oracle.

Reference Pack v0.2 guided the analysis successfully without repository archaeology, but
the strong ordinary postmortem already contained essentially all consequential value.

Result:

> **POSTMORTEM_BASELINE_SUFFICIENT**

This is not contradictory evidence.

It is evidence that "legal hallucination" is too coarse a use category.

## Candidate hypothesis

The next useful hypothesis is conditional:

> **Needle adds material failure-analysis value primarily when the ordinary postmortem
> must preserve non-trivial legal-state, authority-relationship, boundary,
> provenance/reuse or regression-conversion structure.**

Conversely:

> when the legal truth and regression oracle are already obvious from one stable source,
> Needle may add only governance metadata and should not claim material packet value.

This hypothesis is not yet accepted.

## Mode comparison

### USE — selected

Direct use can discriminate the conditional hypothesis better than another broad external
scan.

The next test should not simply choose a "hard-looking" row.

Instead, it should use an **externally defined task stratum** whose structure is materially
different from #349.

The `Hallucination-Free?` study provides such strata independently of Needle.

Its **Treatment (Doctrinal Agreement)** task asks how one Supreme Court case treated
another Supreme Court case it cites, with relations such as followed, distinguished or
overruled.

That is useful because it tests an **authority-relationship reconstruction** job rather
than a single case-metadata fact.

The stratum is defined by the external study, not by Needle taxonomy.

### Important contamination control

During #351 orientation, individual rows/labels from the `Circuit Splits` stratum were
surfaced.

Therefore those rows are **not** clean candidates for the next mechanical selection.

The Treatment stratum definition was inspected, but row outcomes/responses were not.

#353 therefore freezes:

> first complete public Treatment response labelled Hallucination, in published dataset
> order.

No replacement is allowed.

### DISCOVER — not selected

External literature already establishes that legal AI evaluation spans:

- factual recall;
- open-ended doctrine;
- jurisdiction/time-sensitive questions;
- false premises;
- authority treatment.

More literature will not tell Needle whether its packet adds relative value.

The project now needs another controlled use observation.

### CONSOLIDATE — not selected

The current identity already says:

> legal failure analysis / evaluation design / debugging / regression-fixture derivation

That statement does not require every failure to benefit equally.

#339/#349 therefore do not yet create a governance contradiction.

The claim may need narrowing after #353, but not before the conditional hypothesis is
tested.

### REVIEW / RELEASE — not selected

Reference Pack v0.2 just passed its first orthogonal navigation test.

It should not be expanded again before the packet-value boundary is better understood.

The structured external-failure layer remains explicitly unearned.

### MAINTAIN — not selected

No new correctness, integrity, security or cost issue currently dominates the research
question.

## What #353 must discriminate

The useful comparison is not "hard vs easy" in the abstract.

Record observable properties:

- how many authoritative sources/relationships must be reconstructed;
- whether the answer is directly copied from one source or depends on a relationship
  between authorities;
- temporal/version sensitivity;
- jurisdiction/authority sensitivity;
- whether a two-sided boundary changes later reuse;
- whether the regression oracle is already given or must be legally reconstructed;
- whether scientific/reuse status materially changes the artifact.

The project should not invent a numeric complexity score after seeing the result.
