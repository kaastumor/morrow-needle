## Trigger

Three bounded use observations now provide a decision-relevant contrast.

### #339 — material packet value

The strong postmortem correctly recovered the law, but meaningful reusable structure still
had to be formalized:

- historical source-state handling;
- a two-sided doctrinal boundary;
- scientific/exposure status;
- non-trivial regression conversion.

Result:

> **NEEDLE_VALUE_PACK_GAP**

### #349 — postmortem sufficient

The failure was a binary appellate-disposition inversion.

The external row already supplied:

- the question;
- model answer;
- correct answer.

One reported opinion directly supplied the formal disposition.

Reference Pack v0.2 successfully guided the analysis, but full packet work did not
materially improve the artifact.

Result:

> **POSTMORTEM_BASELINE_SUFFICIENT**

### #353 — material packet value

The external Treatment task required:

- reconstructing an inter-authority relationship;
- separating a malformed year from stable reporter-citation identity;
- preserving a proposition-specific boundary;
- deriving a non-trivial regression oracle from the legal relationship.

Result:

> **CONDITIONAL_PACKET_VALUE_SUPPORTED**

## Supported boundary

The accepted evidence now supports a practical allocation rule:

> **Strong ordinary/source-linked postmortem first. Needle earns full packet work only when
> consequential reusable legal relationship/state/boundary/reuse structure remains to be
> formalized.**

Conversely:

> if the legal truth and future regression oracle are already explicit/trivial, Needle
> should not add process merely to make the failure look like a Needle packet.

This is a use-allocation rule.

It is not:

- a population-performance claim;
- a numeric complexity model;
- a proof that every multi-source problem benefits;
- a model/workflow superiority claim.

## Mode comparison

### CONSOLIDATE — selected

The project's durable public/use wording currently says the external job is broadly:

> legal failure analysis / evaluation design / debugging

That remains true, but it does not yet express **first refusal** or the newly supported
conditional application boundary.

Without consolidation, a consumer can reasonably infer:

> every known legal failure should receive the full Needle packet.

#349 demonstrates that this would be ceremony.

The highest-value next move is therefore to encode the boundary in the durable owners:

- strongest postmortem first;
- full packet only if consequential reusable structure remains;
- otherwise stop at the sufficient postmortem.

This protects the positive #339/#353 results from overgeneralization.

### USE — not selected now

A fourth use could test another predicted boundary case.

That remains useful later, especially if it is designed to falsify the conditional rule.

But the current rule is already actionable and bounded enough to improve allocation today.

Running another case before encoding it risks continuing to use stale broad guidance.

### REVIEW / RELEASE — not selected

Reference Pack v0.2 already passed two independent navigation uses.

`STRUCTURED_LAYER_SIGNAL` is only:

> **INDETERMINATE**

The recurring fields have conditional materiality and there is still no canonical
external-analysis membership owner.

No v0.3 or derived packet index is earned now.

### DISCOVER — not selected

The question has moved beyond external precedent.

The strongest uncertainty is no longer whether structured failure analysis can have value;
it is how to allocate the existing method responsibly.

Another literature scan has lower decision value than consolidation.

### MAINTAIN — not selected

No correctness, integrity, security or cost trigger currently dominates.

## Structured-layer consequence

Do not interpret #353's positive result as permission to create structured external-failure
data.

The evidence currently says:

- some packet fields recur;
- some are legitimately absent;
- some are material only on richer failures;

Therefore preserve:

> **STRUCTURED_LAYER_SIGNAL = INDETERMINATE**
