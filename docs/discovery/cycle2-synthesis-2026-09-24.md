Cycle 2 produced useful map expansion rather than a feature list.

Four evidence-anchored searches yielded:

- Run A — `TECHNICAL_STANDARD_AUTHORITY_HANDOFF` → **ADOPT_FOR_EXPERIMENT**
- Run B — `SEARCH_EXECUTION_PROVENANCE_CLOSURE` → **PARK**
- Run C — `OFFICIAL_DERIVED_VIEW_LAG` → **ADOPT_FOR_EXPERIMENT**
- Run D — `SCHOLARLY_STATUS_LATENT_DETECTION` → **ADOPT_FOR_EXPERIMENT**

Only one receives a next experiment.

Selected:

> **Run D — `SCHOLARLY_STATUS_LATENT_DETECTION`**

Reason:

> it has the highest information gain for Needle's **project identity**, not
> merely the highest chance of adding another corpus failure class.

A and C remain evidence-backed parked reserves.

No feature implementation is authorised.

## Did active discovery add useful information?

Yes.

The value was not that three candidates survived.

The useful changes were:

1. one plausible transfer was **killed/parked by a stronger incumbent method**
   rather than converted into Needle work;
2. two legal-adjacent mechanisms were shown to extend beyond their original
   examples;
3. one non-legal domain supplied independent evidence that the surviving
   evaluation protocol may transfer outside legal research;
4. boundaries became sharper:
   - obvious draft/final labeling is not enough for a Needle opportunity;
   - existing method non-adoption is not evidence that a new method is needed;
   - historical snapshots are not "stale" merely because newer state exists;
   - post-publication scholarly status is not equivalent to "all claims false".

That is genuine opportunity-space learning.

## Run-by-run synthesis

### A — technical-standard authority handoff

Working label:

`TECHNICAL_STANDARD_AUTHORITY_HANDOFF`

Evidence:

- ESA final draft RTS can be substantively amended by the Commission;
- completed fixed-overheads and crowdfunding chains show real changes;
- 2026 EBA material shows the authority-handoff mechanism remains current.

Strong alternative:

- EBA status/correspondence;
- EUR-Lex adopted delegated regulation;
- careful official-source research.

Boundary evidence:

- FCA consultation → Policy Statement usually exposes role transition clearly;
- IETF Internet-Draft → RFC status is explicit enough that no Needle-specific
  opportunity is earned.

### Synthesis disposition: PARK / EVIDENCE-BACKED RESERVE

A is a credible future corpus-generalisation experiment.

But even a positive result mainly says:

> Needle has found another legal-information lifecycle failure family.

That is useful coverage, but it does not currently distinguish competing project
identities.

Reopen after the selected D experiment or when an RTS research question becomes
independently consequential.

---

### B — search execution provenance closure

Working label:

`SEARCH_EXECUTION_PROVENANCE_CLOSURE`

Evidence:

- systematic-review search reproducibility problems are severe;
- PRISMA-S and specialist information-science methodology already prescribe
  most of the relevant provenance;
- database state itself is mutable.

### Synthesis disposition: PARK

This is the strongest negative Cycle 2 result.

The target problem is real.

But the evidence says the dominant observed failure is:

- failure to use an existing method completely; plus
- unavoidable / externally controlled database drift.

Needle should not infer:

> reproducibility problem exists → Needle closure pack needed.

Reopen only from a method-compliant artifact that remains materially
unreconstructable because of a concrete unowned closure dimension.

---

### C — official derived-view lag

Working label:

`OFFICIAL_DERIVED_VIEW_LAG`

Evidence:

- EU sanctions consolidated views can lag operative OJ acts;
- official authorities explicitly state that legal acts, not the derived list,
  are binding;
- legislation.gov.uk revised text can have already-effective outstanding
  changes not yet editorially applied;
- Single Market Scoreboard supplies a clean boundary because it declares a
  snapshot/cut-off by design.

### Synthesis disposition: PARK / EVIDENCE-BACKED RESERVE

C supplies strong evidence that #93's
`OFFICIAL_TRACKER_UPDATE_LAG` may be surface-specific wording for a broader
mechanism.

A successful two-case test would improve the corpus taxonomy.

But the current corpus already preserves the central observation-horizon
principle.

Its next experiment therefore has lower information gain than D.

Do not rename the class yet.

---

### D — scholarly-status latent detection

Working label:

`SCHOLARLY_STATUS_LATENT_DETECTION`

Independent evidence:

- AI-assisted scientific research tools can include retracted literature without
  warning;
- a 2025 latent quality-evaluation study produced 6,510 reports without
  surfacing the relevant retraction/correction/problem status;
- a 2026 multi-tool study showed failures both in ordinary research pathways and
  under explicit status questioning.

Strong existing alternative:

- Crossmark;
- Crossref update metadata;
- Retraction Watch;
- publisher notices.

Therefore the opportunity cannot win by retrieving retraction data.

The candidate contribution is evaluation construct discipline:

- DERIVATION vs EVALUATION;
- LATENT_TRAP_DETECTION vs SURFACED_TRAP_ADJUDICATION;
- explicit `as_of` time;
- equivalent current-source access;
- task-specific safe qualification rather than automatic exclusion.

### Synthesis disposition: ADOPT_FOR_EXPERIMENT

D has the highest information gain because it can answer a project-level
question:

> Is Needle's surviving corpus/evaluation contribution fundamentally
> **legal-specific**, or can the evaluation protocol transfer cleanly to another
> consequential document-status domain?

A negative result is highly useful.

A positive result is also useful, but does not automatically redirect Needle
into a scientific product.

## Competing project identities

### Identity 1 — legal adversarial corpus + reusable evaluation protocol

Current incumbent.

This remains the best-supported identity today.

### Identity 2 — legal corpus + mostly legal-specific protocol

Smaller interpretation:

> the protocol looks reusable because its concepts are generic in wording, but
> the actually demonstrated value depends on legal authority/time/source
> semantics.

If D fails, confidence in this identity rises.

### Identity 3 — adversarial document-status evaluation protocol + legal corpus as first mature corpus

Adjacent interpretation:

> the durable contribution is a protocol for preserving consequential
> document-status failure mechanisms and evaluating them without contamination;
> legal research is the first mature corpus, not necessarily the protocol's
> domain boundary.

If D succeeds with minimal adaptation, confidence in this identity rises.

Do **not** adopt Identity 3 before the experiment.

## Why D outranks A and C

### Information gain

A and C mostly ask:

> how broad is the legal corpus taxonomy?

D asks:

> what kind of project is Needle?

That is a larger decision.

### Existing baseline strength

D has unusually strong incumbent infrastructure.

Crossmark / Crossref / Retraction Watch already solve the status-data problem.

Needle therefore cannot win by building retrieval or a status database.

That makes the experiment discriminating.

### Falsifiability

D can fail if:

- legal-specific assumptions leak into the protocol;
- existing scientific evaluation practice already owns the same construct
  controls;
- no fresh latent scientific-status case is consequential;
- the only benefit is terminology/packaging.

### Low implementation cost

The next experiment requires only:

- frozen cases;
- frozen status evidence;
- prompts/rubrics;
- exposure/time declarations;
- comparative execution if the preregistered design justifies it.

No product or persistent infrastructure is required.

## Relative-value question

Cycle 2 did not identify a product/workflow claim strong enough for delivery.

A, C and D are primarily **correctness / validity / evaluation-construct**
opportunities.

Therefore:

> correctness parity cannot be reinterpreted after the fact as product value.

If a future product/workflow projection appears, it must separately show:

1. real difference;
2. user importance;
3. behavioral consequence;
4. adoption/switching plausibility;
5. preserved validity/provenance.

No Cycle 2 candidate currently clears that product gate.

## Anti-theatre review

Cycle 2 produced substantial documentation, so process creep remains a real
risk.

Evidence that the cycle was not purely ceremonial:

- Run B was parked despite a large, important reproducibility literature;
- IETF/FCA analogies were used as boundaries rather than added as opportunities;
- strong incumbents repeatedly narrowed claims;
- no feature was built;
- no opportunity entered the queue merely because a competitor did or did not
  exist;
- only one of three retained candidates receives an experiment.

The process still needs to stay bounded.

Do not create Cycle 3 before the selected experiment changes the map.

## Selected next experiment

Create one bounded issue for:

> **SCHOLARLY STATUS PROTOCOL TRANSFER**

### Claim type

`CORRECTNESS_VALIDITY / EVALUATION_CONSTRUCT`

### Core claim

> The current Needle adversarial-corpus evaluation protocol can represent and
> test latent scholarly-status failures with minimal domain adaptation while
> preserving construct validity around exposure, time and surfaced-vs-latent
> detection.

### Minimum case set

Pre-register four fresh documents:

1. retracted;
2. materially corrected;
3. expression of concern / comparable warning state;
4. unchanged matched control.

Cases used to design the mechanism are DERIVATION and may not count as fresh
validation.

### Required `as_of` state

Freeze for every case:

- publication identity;
- relevant update/status event;
- update/status effective/published time;
- evaluation `as_of`;
- authoritative status evidence;
- exposure classification.

### Evaluation modes

Primary:

`LATENT_TRAP_DETECTION`

Optional calibration:

`SURFACED_TRAP_ADJUDICATION`

Never blend the two into one project claim.

### Strong comparator

Give equal current web/source access.

Do not manufacture an advantage by withholding Crossmark/Crossref/publisher
status from the baseline.

### Kill rule

Reject general protocol transfer if:

- existing protocol requires substantial legal-specific schema/semantics;
- existing scientific evaluation practice already owns all discriminating
  controls;
- the fresh latent cases do not make scholarly status consequential;
- or the experiment only demonstrates that systems need current retraction
  metadata.

### Success boundary

Success is not:

> Needle detects retractions.

Success is:

> the existing evaluation protocol transfers with minimal change and yields a
> cleaner, falsifiable latent-status evaluation construct whose result cannot be
> explained by unequal status-data access or surfaced prompting.
