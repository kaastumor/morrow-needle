# Issue #357 — conditional failure-analysis use-contract consolidation

Date: 2026-09-26  
Disposition: **CONSOLIDATED**

## Trigger

Three bounded USE observations support a practical allocation boundary:

- #339 — material packet value after a strong postmortem because doctrine/source-state,
  boundary and regression structure still required formalization;
- #349 — strong postmortem sufficient for a binary single-source disposition error;
- #353 — material packet value for an inter-authority treatment relationship with malformed
  metadata and a non-trivial regression oracle.

## Durable rule

> **Strong source-linked postmortem first. Full Needle packet work is earned only when
> consequential reusable legal relationship/state/boundary/reuse structure remains to
> formalize.**

A sufficient postmortem is an accepted endpoint.

Needle must not add structure ceremonially when:

- truth is already explicit in one stable source;
- the expected answer is already supplied;
- the future regression oracle is nearly tautological;
- the extra artifact adds only labels or governance metadata.

Signals that fuller packet work may be worthwhile include:

- multi-authority or legal-state reconstruction;
- material historical/source-identity handling;
- consequential boundary/opposite-error preservation;
- scientific/exposure status that materially changes future reuse;
- non-trivial regression conversion / PASS-FAIL design.

These signals are not a score and are not necessary/sufficient conditions.
